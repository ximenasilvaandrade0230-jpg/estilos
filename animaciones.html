1. Teoría básica

CSS permite animar elementos sin JavaScript de dos maneras:

  • Transiciones (transition): suavizan el cambio de una propiedad cuando ocurre un evento, como :hover.
  • Animaciones con keyframes (@keyframes): definen pasos (from/to o porcentajes) y se aplican con animation.

Propiedades de animation: animation-name, animation-duration, animation-timing-function, animation-delay, animation-iteration-count (por ejemplo infinite) y animation-direction.

2. Cinco ejemplos básicos

Ejemplo 1: Transición con hover

Pasa el mouse sobre el cuadro: el color cambia suavemente.

Pasa el mouse

HTML:

<div class="e1">Pasa el mouse</div>

CSS:

.e1 { width: 150px; padding: 20px; background: #cfe3ff; transition: background 0.5s, transform 0.5s; text-align: center; }
.e1:hover { background: #c2185b; color: white; transform: scale(1.1); }

Ejemplo 2: Movimiento con @keyframes

El cuadro se desplaza de izquierda a derecha y regresa.

HTML:

<div class="e2"></div>

CSS:

@keyframes mover { from { margin-left: 0; } to { margin-left: 200px; } }
.e2 { width: 60px; height: 60px; background: #c2185b; animation: mover 2s infinite alternate; }

Ejemplo 3: Rotación infinita

El cuadro gira de forma continua.

HTML:

<div class="e3"></div>

CSS:

@keyframes girar { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }
.e3 { width: 70px; height: 70px; margin: 15px; background: #1a4f9c; animation: girar 2s linear infinite; }

Ejemplo 4: Efecto pulso

El círculo crece y se encoge con porcentajes.

HTML:

<div class="e4"></div>

CSS:

@keyframes pulso { 0% { transform: scale(1); } 50% { transform: scale(1.3); } 100% { transform: scale(1); } }
.e4 { width: 70px; height: 70px; margin: 15px; border-radius: 50%; background: #2a7a2a; animation: pulso 1.5s ease-in-out infinite; }

Ejemplo 5: Cambio de color

El fondo recorre varios colores.

Arcoíris

HTML:

<div class="e5">Arcoíris</div>

CSS:

@keyframes colores { 0% { background: red; } 33% { background: gold; } 66% { background: dodgerblue; } 100% { background: red; } }
.e5 { width: 150px; padding: 25px; color: white; text-align: center; animation: colores 4s linear infinite; }
