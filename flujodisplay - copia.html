FLUJO NORMAL Y DISPLAY

REGRESAR

1. Teoría básica

El flujo normal es la forma en que el navegador acomoda los elementos si no le damos otras instrucciones: de arriba hacia abajo, uno tras otro.

La propiedad display controla cómo se comporta cada elemento dentro de ese flujo:

  • block: ocupa todo el ancho y empieza en una línea nueva (div, p, h1).
  • inline: solo ocupa lo que mide su contenido y no rompe la línea (span, a).
  • inline-block: va en línea pero permite width y height.
  • none: oculta el elemento y no ocupa espacio.
  • flex y grid: modelos de diseño avanzados.

2. Cinco ejemplos básicos

Ejemplo 1: display: block

Los elementos block ocupan todo el ancho disponible, uno debajo del otro.

Bloque 1
Bloque 2

HTML:

<div class="e1"><div>Bloque 1</div><div>Bloque 2</div></div>

CSS:

.e1 div { background: #cfe3ff; margin: 5px 0; padding: 8px; }

Ejemplo 2: display: inline

Los span son inline: se acomodan en la misma línea.

UnoDosTres

HTML:

<div class="e2"><span>Uno</span><span>Dos</span><span>Tres</span></div>

CSS:

.e2 span { background: #ffd9b3; padding: 8px; }

Ejemplo 3: display: inline-block

Van en línea, pero aceptan ancho y alto.

Caja ACaja BCaja C

HTML:

<div class="e3"><span>Caja A</span><span>Caja B</span><span>Caja C</span></div>

CSS:

.e3 span { display: inline-block; width: 100px; height: 50px; background: #d4f5d4; border: 2px solid #2a7a2a; text-align: center; }

Ejemplo 4: display: none

El segundo bloque desaparece y no deja espacio.

Visible 1
Oculto
Visible 2

HTML:

<div class="e4"><div class="a">Visible 1</div><div class="b">Oculto</div><div class="c">Visible 2</div></div>

CSS:

.e4 .a, .e4 .c { background: #ffe0ec; padding: 8px; }
.e4 .b { display: none; }

Ejemplo 5: Menú horizontal con display

Una lista (block) se convierte en menú cambiando li a inline-block.

  • Inicio
  • Hobbies
  • Contacto

HTML:

<nav class="e5"><ul><li>Inicio</li><li>Hobbies</li><li>Contacto</li></ul></nav>

CSS:

.e5 ul { list-style: none; padding: 0; }
.e5 li { display: inline-block; background: #c2185b; color: white; padding: 8px 14px; margin-right: 4px; }
