BORDES EN CSS

REGRESAR

1. Teoría básica

La propiedad border dibuja una línea alrededor de un elemento. Se compone de tres valores: grosor (border-width), estilo (border-style) y color (border-color), que se pueden escribir juntos: border: 3px solid red;.

Los estilos más usados son solid, dashed, dotted y double. También se pueden aplicar bordes por lado (border-top, border-left...) y redondear esquinas con border-radius.

2. Cinco ejemplos básicos

Ejemplo 1: Estilos de borde

Cuatro estilos distintos: solid, dashed, dotted y double.

solid
dashed
dotted
double

HTML:

<div class="e1 a">solid</div>
<div class="e1 b">dashed</div>
<div class="e1 c">dotted</div>
<div class="e1 d">double</div>

CSS:

.e1 { padding: 8px; margin: 8px 0; }
.e1.a { border: 4px solid #c2185b; }
.e1.b { border: 4px dashed #c2185b; }
.e1.c { border: 4px dotted #c2185b; }
.e1.d { border: 6px double #c2185b; }

Ejemplo 2: Bordes por lado

Cada lado puede tener un borde distinto.

Cuatro colores

HTML:

<div class="e2">Cuatro colores</div>

CSS:

.e2 { padding: 15px; border-top: 6px solid red; border-right: 6px solid green; border-bottom: 6px solid blue; border-left: 6px solid orange; }

Ejemplo 3: Esquinas redondeadas

border-radius suaviza las esquinas.

Caja con esquinas redondas

HTML:

<div class="e3">Caja con esquinas redondas</div>

CSS:

.e3 { padding: 20px; border: 3px solid #333; border-radius: 15px; background: #fff3cd; }

Ejemplo 4: Círculo

Con width = height y border-radius: 50% se obtiene un círculo.

HTML:

<div class="e4"></div>

CSS:

.e4 { width: 100px; height: 100px; border: 5px solid #1a4f9c; border-radius: 50%; background: #cfe3ff; }

Ejemplo 5: Esquinas diferentes

Se pueden dar valores distintos a cada esquina.

Esquinas alternadas

HTML:

<div class="e5">Esquinas alternadas</div>

CSS:

.e5 { padding: 25px; border: 3px solid #2a7a2a; border-radius: 40px 0 40px 0; background: #d4f5d4; }
