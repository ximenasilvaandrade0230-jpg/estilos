1. Teoría básica

Flexbox es un modelo de diseño que acomoda elementos en una sola dimensión (fila o columna) de forma flexible. Se activa con display: flex en el contenedor (padre); sus hijos se convierten en "ítems flex".

Propiedades principales del contenedor:

  • flex-direction: row (fila) o column (columna).
  • justify-content: alineación en el eje principal.
  • align-items: alineación en el eje cruzado.
  • flex-wrap y gap: saltos de línea y separación entre ítems.

2. Cinco ejemplos básicos

Ejemplo 1: display: flex

Los hijos se acomodan en una fila.

1
2
3

HTML:

<div class="e1"><div>1</div><div>2</div><div>3</div></div>

CSS:

.e1 { display: flex; }
.e1 div { background: #cfe3ff; border: 2px solid #1a4f9c; padding: 15px; }

Ejemplo 2: justify-content: space-between

Reparte el espacio sobrante entre los ítems.

A
B
C

HTML:

<div class="e2"><div>A</div><div>B</div><div>C</div></div>

CSS:

.e2 { display: flex; justify-content: space-between; }
.e2 div { background: #ffd9b3; border: 2px solid #c25b00; padding: 15px; }

Ejemplo 3: align-items: center

Centra los ítems verticalmente dentro de un contenedor con altura.

Centrado

HTML:

<div class="e3"><div>Centrado</div></div>

CSS:

.e3 { display: flex; justify-content: center; align-items: center; height: 150px; background: #eef; }
.e3 div { background: #c2185b; color: white; padding: 15px; }

Ejemplo 4: flex-direction: column

Los ítems se apilan en columna.

Arriba
Centro
Abajo

HTML:

<div class="e4"><div>Arriba</div><div>Centro</div><div>Abajo</div></div>

CSS:

.e4 { display: flex; flex-direction: column; gap: 8px; }
.e4 div { background: #d4f5d4; border: 2px solid #2a7a2a; padding: 10px; }

Ejemplo 5: flex: 1 y gap

flex: 1 hace que cada ítem ocupe el mismo espacio.

Uno
Dos
Tres

HTML:

<div class="e5"><div>Uno</div><div>Dos</div><div>Tres</div></div>

CSS:

.e5 { display: flex; gap: 10px; }
.e5 div { flex: 1; background: #ffe0ec; border: 2px solid #c2185b; padding: 15px; text-align: center; }
