1. Teoría básica

En CSS todo elemento HTML es una caja rectangular. Esa caja está formada por cuatro capas, de adentro hacia afuera:

  • Content (contenido): el texto o imagen del elemento.
  • Padding (relleno): espacio entre el contenido y el borde.
  • Border (borde): la línea que rodea al padding.
  • Margin (margen): espacio exterior que separa la caja de las demás.

Por defecto (box-sizing: content-box) el width solo mide el contenido, y el padding y el borde se suman. Con box-sizing: border-box el ancho incluye padding y borde, lo que facilita calcular tamaños.

2. Cinco ejemplos básicos

Ejemplo 1: Padding

El padding crea espacio dentro de la caja, entre el contenido y el borde.

Texto con padding de 30px

HTML:

<div class="e1">Texto con padding de 30px</div>

CSS:

.e1 { padding: 30px; background: #cfe3ff; border: 2px solid #1a4f9c; }

Ejemplo 2: Margin

El margin separa la caja de otros elementos. Aquí hay 30px entre las dos cajas.

Caja 1
Caja 2

HTML:

<div class="e2">Caja 1</div>
<div class="e2">Caja 2</div>

CSS:

.e2 { margin-bottom: 30px; padding: 10px; background: #ffd9b3; border: 2px solid #c25b00; }

Ejemplo 3: Border + width (content-box)

Ancho 200px + padding 20px×2 + borde 10px×2 = 260px reales.

content-box

HTML:

<div class="e3">content-box</div>

CSS:

.e3 { width: 200px; padding: 20px; border: 10px solid #36a; background: #eef; box-sizing: content-box; }

Ejemplo 4: box-sizing: border-box

Mismo código, pero el ancho de 200px ya incluye padding y borde.

border-box

HTML:

<div class="e4">border-box</div>

CSS:

.e4 { width: 200px; padding: 20px; border: 10px solid #a36; background: #fee; box-sizing: border-box; }

Ejemplo 5: Centrar con margin auto

Con un ancho definido, margin: 0 auto centra la caja horizontalmente.

Caja centrada

HTML:

<div class="e5">Caja centrada</div>

CSS:

.e5 { width: 50%; margin: 0 auto; padding: 15px; text-align: center; background: #d4f5d4; border: 2px solid #2a7a2a; }
