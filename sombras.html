SOMBRAS EN CSS

REGRESAR

1. Teoría básica

Las sombras dan profundidad a la página. Hay dos propiedades principales:

  • box-shadow: sombra de la caja. Sintaxis: desplazamiento-x desplazamiento-y desenfoque expansión color. Con la palabra inset la sombra va hacia adentro.
  • text-shadow: sombra del texto. Sintaxis: desplazamiento-x desplazamiento-y desenfoque color.

2. Cinco ejemplos básicos

Ejemplo 1: Sombra básica

5px a la derecha, 5px hacia abajo, 10px de desenfoque.

Sombra gris

HTML:

<div class="e1">Sombra gris</div>

CSS:

.e1 { width: 200px; padding: 20px; background: white; box-shadow: 5px 5px 10px gray; }

Ejemplo 2: Sombra suave de color

Un desenfoque grande con color transparente da un efecto elegante.

Sombra rosa suave

HTML:

<div class="e2">Sombra rosa suave</div>

CSS:

.e2 { width: 200px; padding: 20px; background: white; box-shadow: 0 10px 30px rgba(194, 24, 91, 0.5); }

Ejemplo 3: Sombra interna (inset)

inset dibuja la sombra dentro de la caja.

Sombra inset

HTML:

<div class="e3">Sombra inset</div>

CSS:

.e3 { width: 200px; padding: 20px; background: #eee; box-shadow: inset 0 0 15px #555; }

Ejemplo 4: Sombra en texto

text-shadow aplica sombra a las letras.

Texto con sombra

HTML:

<p class="e4">Texto con sombra</p>

CSS:

.e4 { font-size: 36px; font-weight: bold; color: #c2185b; text-shadow: 3px 3px 5px #999; }

Ejemplo 5: Sombras múltiples

Se pueden separar varias sombras con comas.

Dos sombras

HTML:

<div class="e5">Dos sombras</div>

CSS:

.e5 { width: 200px; padding: 20px; background: white; box-shadow: 5px 5px 0 #c2185b, 10px 10px 0 #1a4f9c; }
