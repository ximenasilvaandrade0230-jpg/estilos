1. Teoría básica

Bootstrap es un framework de CSS (y JavaScript) que ofrece clases ya hechas para crear páginas responsivas rápidamente: botones, tarjetas, tablas, barras de navegación y una cuadrícula de 12 columnas.

La forma más sencilla de incluirlo es mediante un CDN. Se agrega el enlace al CSS dentro del <head> y, opcionalmente, el script de JavaScript antes de cerrar el </body>:

<head>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    ...
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>

Esta misma página ya tiene Bootstrap incluido, por eso los ejemplos de abajo funcionan solo con clases.

2. Cinco ejemplos básicos

Ejemplo 1: Botones

Las clases btn y btn-* dan estilo a los botones.

HTML:

<button class="btn btn-primary">Primario</button>
<button class="btn btn-success">Éxito</button>
<button class="btn btn-danger">Peligro</button>

Ejemplo 2: Alertas

La clase alert muestra mensajes de colores.

¡Todo salió bien!
Cuidado con este mensaje.

HTML:

<div class="alert alert-success">¡Todo salió bien!</div>
<div class="alert alert-warning">Cuidado con este mensaje.</div>

Ejemplo 3: Cuadrícula de 12 columnas

row y col-* dividen la fila; aquí 3 columnas de 4 espacios cada una.

col-4
col-4
col-4

HTML:

<div class="row text-center">
    <div class="col-4 bg-primary text-white p-3">col-4</div>
    <div class="col-4 bg-secondary text-white p-3">col-4</div>
    <div class="col-4 bg-dark text-white p-3">col-4</div>
</div>

Ejemplo 4: Tarjeta (card)

El componente card agrupa título, texto y botón.

Mi tarjeta

Texto de ejemplo con Bootstrap.

Aceptar

HTML:

<div class="card" style="width: 18rem;">
    <div class="card-body">
        <h5 class="card-title">Mi tarjeta</h5>
        <p class="card-text">Texto de ejemplo con Bootstrap.</p>
        <a href="#" class="btn btn-primary">Aceptar</a>
    </div>
</div>

Ejemplo 5: Tabla con estilo

table y table-striped dan una tabla con filas alternadas.

#Materia
1Programación
2Matemáticas
3Inglés

HTML:

<table class="table table-striped">
    <thead><tr><th>#</th><th>Materia</th></tr></thead>
    <tbody>
        <tr><td>1</td><td>Programación</td></tr>
        <tr><td>2</td><td>Matemáticas</td></tr>
        <tr><td>3</td><td>Inglés</td></tr>
    </tbody>
</table>
