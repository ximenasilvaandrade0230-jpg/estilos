1. Teoría básica

La propiedad position define cómo se ubica un elemento. Se combina con top, right, bottom y left:

  • static: valor por defecto, sigue el flujo normal.
  • relative: se desplaza respecto a su posición original.
  • absolute: se ubica respecto al ancestro posicionado más cercano.
  • fixed: se ubica respecto a la ventana y no se mueve al hacer scroll.
  • sticky: se comporta como relative hasta que se hace scroll y entonces se "pega".

z-index controla qué elemento queda encima cuando se traslapan. Ejemplo de fixed: .boton { position: fixed; bottom: 20px; right: 20px; }

2. Cinco ejemplos básicos

Ejemplo 1: position: static

Es el valor normal. top y left no tienen efecto.

Estoy en el flujo normal

HTML:

<div class="e1">Estoy en el flujo normal</div>

CSS:

.e1 { position: static; top: 50px; left: 50px; background: #eee; padding: 15px; }

Ejemplo 2: position: relative

La caja se mueve 20px abajo y 40px a la derecha de donde estaría.

Desplazado con relative

HTML:

<div class="e2">Desplazado con relative</div>

CSS:

.e2 { position: relative; top: 20px; left: 40px; background: #cfe3ff; padding: 15px; width: 200px; }

Ejemplo 3: position: absolute

El hijo se ubica en la esquina inferior derecha del padre (que es relative).

Padre
Hijo absolute

HTML:

<div class="e3">Padre<div class="hijo">Hijo absolute</div></div>

CSS:

.e3 { position: relative; height: 120px; background: #eef; border: 2px solid #36a; }
.e3 .hijo { position: absolute; bottom: 10px; right: 10px; background: #c2185b; color: white; padding: 8px; }

Ejemplo 4: z-index

Dos cajas traslapadas: la de mayor z-index queda arriba.

z-index 2
z-index 1

HTML:

<div class="e4"><div class="a">z-index 2</div><div class="b">z-index 1</div></div>

CSS:

.e4 { position: relative; height: 130px; }
.e4 div { position: absolute; width: 100px; height: 100px; color: white; padding: 5px; }
.e4 .a { background: #c2185b; top: 0; left: 0; z-index: 2; }
.e4 .b { background: #1a4f9c; top: 30px; left: 40px; z-index: 1; }
