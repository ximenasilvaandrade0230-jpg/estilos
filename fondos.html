1. Teoría básica

Las propiedades de fondo permiten decorar el área detrás del contenido de un elemento:

  • background-color: color sólido.
  • background-image: imagen o degradado (url(), linear-gradient()).
  • background-repeat: si la imagen se repite o no.
  • background-size y background-position: tamaño y ubicación de la imagen.

También existe la forma abreviada background, que reúne todas.

2. Cinco ejemplos básicos

Ejemplo 1: Color de fondo

background-color con un nombre o código hexadecimal.

Fondo rosa

HTML:

<div class="e1">Fondo rosa</div>

CSS:

.e1 { background-color: #ffe0ec; padding: 20px; }

Ejemplo 2: Degradado lineal

linear-gradient mezcla dos o más colores.

Degradado de izquierda a derecha

HTML:

<div class="e2">Degradado de izquierda a derecha</div>

CSS:

.e2 { background: linear-gradient(to right, #ff9a9e, #fad0c4, #a1c4fd); padding: 30px; }

Ejemplo 3: Imagen de fondo

background-image con background-size: cover para cubrir toda la caja.

Imagen de fondo

HTML:

<div class="e3">Imagen de fondo</div>

CSS:

.e3 { height: 150px; background-image: url('img/j.jpg'); background-size: cover; background-position: center; color: white; padding: 10px; }

Ejemplo 4: Imagen repetida

background-repeat y background-size crean un patrón.

HTML:

<div class="e4"></div>

CSS:

.e4 { height: 120px; background-image: url('img/j.jpg'); background-size: 40px; background-repeat: repeat; }

Ejemplo 5: Color con transparencia

rgba() permite controlar la opacidad del fondo.

Fondo semitransparente

HTML:

<div class="e5">Fondo semitransparente</div>

CSS:

.e5 { padding: 25px; background-color: rgba(194, 24, 91, 0.3); border: 2px solid #c2185b; }
