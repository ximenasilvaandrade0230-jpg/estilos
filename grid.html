1. Teoría básica

CSS Grid es un sistema de diseño en dos dimensiones: filas y columnas al mismo tiempo. Se activa con display: grid en el contenedor.

  • grid-template-columns / grid-template-rows: definen las columnas y filas.
  • fr: unidad fraccional que reparte el espacio disponible.
  • gap: separación entre celdas.
  • grid-column y grid-row: permiten que un elemento ocupe varias celdas.
  • grid-template-areas: acomodo por nombres de áreas.

2. Cinco ejemplos básicos

Ejemplo 1: Tres columnas iguales

repeat(3, 1fr) crea tres columnas del mismo tamaño.

1
2
3

HTML:

<div class="e1"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div></div>

CSS:

.e1 { display: grid; grid-template-columns: repeat(3, 1fr); }
.e1 div { background: #cfe3ff; border: 2px solid #1a4f9c; padding: 15px; text-align: center; }

Ejemplo 3: Columnas de distinto tamaño

1fr 2fr: la segunda columna es el doble de ancha.

1fr
2fr

HTML:

<div class="e3"><div>1fr</div><div>2fr</div></div>

CSS:

.e3 { display: grid; grid-template-columns: 1fr 2fr; gap: 10px; }
.e3 div { background: #d4f5d4; padding: 15px; text-align: center; }

Ejemplo 4: Ocupar varias columnas

grid-column: span 2 hace que un elemento ocupe dos columnas.

Ocupa 2
1
2
3
4

HTML:

<div class="e4"><div class="ancho">Ocupa 2</div><div>1</div><div>2</div><div>3</div><div>4</div></div>

CSS:

.e4 { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }
.e4 div { background: #ffe0ec; padding: 15px; text-align: center; }
.e4 .ancho { grid-column: span 2; background: #c2185b; color: white; }

Ejemplo 5: Áreas con nombre

grid-template-areas permite dibujar el diseño de la página.

Encabezado
Menú
Contenido
Pie

HTML:

<div class="e5"><div class="enc">Encabezado</div><div class="menu">Menú</div><div class="cont">Contenido</div><div class="pie">Pie</div></div>

CSS:

.e5 { display: grid; grid-template-columns: 1fr 3fr; grid-template-areas: "encabezado encabezado" "menu contenido" "pie pie"; gap: 8px; }
.e5 div { padding: 15px; text-align: center; color: white; }
.e5 .enc { grid-area: encabezado; background: #c2185b; }
.e5 .menu { grid-area: menu; background: #1a4f9c; }
.e5 .cont { grid-area: contenido; background: #2a7a2a; }
.e5 .pie { grid-area: pie; background: #555; }
